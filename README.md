# VIBE

**Visual Interactive Bike Experience**  
**騎感｜RKL 自行車互動體驗平台**

[![Live Demo](https://img.shields.io/badge/Live%20Demo-VIBE%20Geometry-E2703A?style=flat-square)](https://baiqi-tw.github.io/RKL_VIBE/)
[![GitHub](https://img.shields.io/badge/GitHub-BAIQI--TW%2FRKL__VIBE-181717?style=flat-square&logo=github)](https://github.com/BAIQI-TW/RKL_VIBE)

***Explore the Bike. Experience the Difference.***

VIBE 是 RIKULAU（台灣雲豹自行車）的專屬產品互動體驗平台。透過 3D 即時視覺化、幾何數據、尺寸探索與產品配置介面，協助使用者深入了解車款調性、比較尺寸差異，並進一步探索進階的客製化規格配置。

目前平台以 **VIBE Geometry（幾何探索）** 為核心，整合車架幾何查詢、騎士尺寸參考、車架幾何客製、3D 整車外觀配置及扭力巡檢等功能。

**[開啟 RKL VIBE｜VIBE Geometry](https://baiqi-tw.github.io/RKL_VIBE/)**

## 功能總覽

### 1. 車架幾何探索
- 瀏覽 RKL 各車款與全尺寸的完整幾何資料。
- 透過幾何數據表快速查詢車架尺寸與對應數值。
- 切換車架尺寸時，同步即時更新 3D 車架模型示意。
- 以疊圖模式直覺比較不同尺寸間的幾何差異。
- 檢視胎寬、頭碗組等相關配件的視覺示意。
- 支援 3D 畫面與幾何數據表雙向互動對照。

### 2. 騎士尺寸參考
- 輸入身高、跨高及手臂長等騎士關鍵數據。
- 即時取得合適的車架尺寸建議。
- 將個人關鍵身體數據與車架幾何資料進行搭配檢視。

> **提醒：** 系統提供之尺寸建議僅供初步選購參考；實際車架尺寸仍建議依個人身體條件、騎乘習慣及專業 Fitting 評估確認。

### 3. 車架幾何客製
- 自訂輸入客製化車架幾何參數。
- 內建即時欄位驗證，確保輸入數值的合理性。
- 即時預覽參數調整後的 3D 車架幾何變化。
- 匯出客製化幾何需求表單，便於後續討論與製程確認。

### 4. 3D 整車配置探索
- 自訂車架表面處理工藝與塗裝色彩。
- 設定鈦合金陽極處理色澤與品牌主視覺配色。
- 調整座管束、頭碗組、鈦合金螺絲及金屬小件配色。
- 切換不同品牌傳動系統，預覽整車視覺搭配效果。
- 調整零組件透明度，聚焦檢視車架結構並高效定調主視覺。
- 探索客製化塗裝方案與加購套件等進階配置。

> **說明：** 3D 模型呈現參數式的產品即時外觀變化，協助使用者預覽不同配置下的擬真視覺效果。

### 5. 扭力巡檢
- 透過 3D 互動模型直覺辨識各鎖固巡檢部位。
- 引導完成全車 16 個關鍵部位的扭力巡檢流程。
- 即時記錄巡檢狀態，並顯示完成進度與評估分數。
- 提供各部位對應的標準扭力值參考資訊。

> **安全提示：** 實際安裝與維修保養時，請務必依各零組件及車架製造商提供的官方規格進行操作。

### 6. 設定檔與資料輸出
- 將客製需求表單匯出為 Markdown（`.md`）或純文字（`.txt`）格式。
- 將目前的 3D 配置匯出為 `.md` 設定檔，方便保存與日後匯入還原。
- 支援快速複製、貼上並套用設定檔文字。
- 內建範例設定檔，一鍵載入即可快速體驗平台操作。

> **說明：** 設定檔可完整保存車型、尺寸、塗裝顏色、加購項目、騎士與幾何客製參數、零組件透明度及畫質材質等設定（不包含鏡頭視角與當前分頁位置）。

# VIBE (English Version)

**Visual Interactive Bike Experience**

[![Live Demo](https://img.shields.io/badge/Live%20Demo-VIBE%20Geometry-E2703A?style=flat-square)](https://baiqi-tw.github.io/RKL_VIBE/)

***Explore the Bike. Experience the Difference.***

VIBE is the exclusive interactive product experience platform for RIKULAU. Through real-time 3D visualization, geometry data, size exploration, and product configuration interfaces, it helps users deeply understand bike characteristics, compare sizing differences, and explore advanced custom specifications.

Currently, the platform centers around **VIBE Geometry**, integrating frame geometry lookup, rider sizing reference, custom frame geometry, 3D bike configuration, and torque inspection.

For the best experience, we recommend using a desktop computer or a mid-to-high-end mobile device with WebGL support, and maintaining a stable internet connection.

## Features Overview

### 1. Frame Geometry Exploration
- Browse complete geometry data for all RKL models and sizes.
- Quickly look up frame sizes and corresponding values via the geometry data table.
- Real-time updates of the 3D frame model when switching sizes.
- Intuitively compare geometry differences between sizes using the overlay mode.
- View visual representations of accessories like tire clearance and headsets.
- Two-way interactive sync between the 3D view and the geometry data table.

### 2. Rider Sizing Reference
- Input rider body metrics such as height, inseam, and arm length.
- Get instant frame size recommendations.
- Pair personal body metrics with frame geometry data for visual reference.

> **Note:** Sizing recommendations are for preliminary reference only; the actual frame size should be confirmed based on personal body conditions, riding habits, and professional fitting.

### 3. Custom Frame Geometry
- Input custom frame geometry parameters.
- Built-in real-time field validation to ensure reasonable values.
- Instantly preview the 3D frame geometry changes after parameter adjustments.
- Export the custom geometry request form for further discussion and manufacturing confirmation.

### 4. 3D Bike Configuration
- Customize frame surface finishes and paint colors.
- Set titanium anodized colors and brand logo color schemes.
- Adjust the colors of seat clamps, headsets, titanium bolts, and small metal parts.
- Switch between different drivetrain brands to preview the overall visual effect.
- Adjust component transparency to focus on the frame structure and efficiently define the main visual theme.
- Explore advanced configurations like custom paint schemes and add-on kits.

> **Info:** The 3D model is used to present the product's appearance and real-time parametric changes, helping users preview highly realistic visual effects under different configurations.

### 5. Torque Inspection
- Intuitively identify locking inspection points through the interactive 3D model.
- Step-by-step guidance for a 16-point full-bike torque inspection process.
- Real-time tracking of inspection status, progress, and evaluation score.
- Provide standard reference torque values for corresponding parts.

> **Safety Warning:** During actual installation and maintenance, please be sure to strictly follow the official specifications provided by component and frame manufacturers.

### 6. Profiles and Data Export
- Export the custom request form as Markdown (`.md`) or plain text (`.txt`) format.
- Export the current 3D configuration as an `.md` profile for easy saving and future restoration.
- Support quick copy, paste, and apply of profile text.
- Built-in preset profiles for quick loading and experiencing the platform.

> **Info:** The profile fully saves the model, size, paint colors, add-ons, rider and custom geometry parameters, component transparency, and graphics/material settings (excluding camera perspective and current tab position).
