# RKL VIBE

**Visual Interactive Bike Experience**\
**騎感｜RKL 自行車互動體驗平台**

[![Live
Demo](https://img.shields.io/badge/Live%20Demo-VIBE%20Geometry-E2703A?style=flat-square)](https://baiqi-tw.github.io/RKL_VIBE/)
[![GitHub](https://img.shields.io/badge/GitHub-BAIQI--TW%2FRKL__VIBE-181717?style=flat-square&logo=github)](https://github.com/BAIQI-TW/RKL_VIBE)

**Explore the Bike. Experience the Difference.**

VIBE 是 RIKULAU [台灣雲豹自行車] 的自行車產品互動體驗平台。透過 3D
即時視覺化、幾何資料、尺寸探索與產品配置介面，協助使用者理解車款調性、比較尺寸差異，並探索更細部的客製化服務配置。

目前平台以 **VIBE Geometry（幾何探索）**
為核心，整合車架幾何查詢、騎士尺寸參考、車架幾何客製、3D
外觀設定及扭力巡檢等功能。

## 功能總覽

### 1. 車架幾何探索

-   瀏覽 RKL 車款及各尺寸的幾何資料。
-   透過幾何表查詢車架尺寸與對應數值。
-   切換尺寸時，同步更新 3D 車架示意。
-   以疊圖方式比較不同尺寸的幾何差異。
-   查看胎寬、頭碗組等相關示意配件。
-   在 3D 畫面與幾何資料之間互相對照。

### 2. 騎士尺寸參考

-   輸入騎士身高、跨高及手臂長等身體尺寸。
-   取得車架尺寸參考建議。
-   將騎士尺寸與車架幾何資料搭配檢視。

尺寸建議提供初步選擇參考；實際車架尺寸仍應依個人身體條件、騎乘需求及專業評估確認。

### 3. 車架幾何客製

-   輸入客製車架幾何參數。
-   透過即時欄位驗證檢查輸入內容。
-   觀察參數變更後的 3D 車架示意。
-   輸出客製需求資料，供後續討論與確認。

系統提供多項幾何輸入及表單輸出功能，協助整理車架客製需求。

### 4. 3D 整車配置探索

-   調整車架表面處理及顏色。
-   設定鈦合金陽極色與 Logo 顏色。
-   調整座管束、頭碗組、鈦螺絲及金屬小件等顏色。
-   調整不同品牌傳動系統的視覺效果搭配。
-   藉由調整零組件透明度，將主視覺做更有效率的定調。
-   探索塗裝客製及加購套件等設定。

3D 模型用於呈現產品外觀及參數式即時變化，協助使用者體驗不同設定的擬真效果。

### 5. 扭力巡檢

-   透過 3D 零件位置辨識巡檢部位。
-   提供 16 個部位的扭力巡檢流程。
-   記錄巡檢設定並顯示完成進度與分數。
-   提供各部位的扭力參考資訊。

實際安裝及維修時，請依零件與車架製造商提供的規格操作。

### 6. 設定檔與資料輸出

-   將客製需求表單匯出為 Markdown（`.md`）或純文字（`.txt`）。
-   將目前 3D 設定匯出為 `.md`，供保存及日後匯入還原。
-   複製、貼上及套用設定文字。
-   使用範例設定快速體驗系統操作。

設定檔可保存車型、尺寸、塗裝顏色、加購項目、騎士與幾何客製、透明度及畫質材質等設定；不包含鏡頭視角與分頁位置。
